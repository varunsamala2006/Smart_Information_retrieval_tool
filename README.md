1. Introduction

The Retrieval Tool is a web-based application designed to generate advanced search queries automatically from a user-provided keyword.

Searching for specific information on the internet can sometimes require complex search operators such as intitle:, inurl:, filetype:, site:, and intext:. Manually constructing these queries can be time-consuming, especially for users who are unfamiliar with advanced search techniques.

The proposed Retrieval Tool provides a simple and attractive graphical interface where the user enters a keyword. The application automatically generates a collection of predefined search queries and provides a Search button for each query. Clicking the button opens the corresponding search in Google.

The application is developed using:

HTML – Structure of the webpage
CSS – Styling, layout, animations, and visual effects
JavaScript – Query generation and dynamic webpage interaction
Google Search – Execution of generated search queries
